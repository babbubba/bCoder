# Contributing

- un task per pull request;
- nessun task senza criteri di accettazione;
- aggiornare test e documentazione;
- registrare decisioni architetturali con ADR;
- non cambiare dipendenze principali senza motivazione;
- non aumentare privilegi degli strumenti senza threat review;
- non introdurre provider esterni non allow-listed;
- allegare output build/test alla PR.
