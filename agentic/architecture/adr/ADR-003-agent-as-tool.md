# Agent-as-tool come delega primaria

- Stato: Accepted
- Data: 2026-08-05

## Decisione

Il manager mantiene controllo e delega sotto-task tramite strumenti tipizzati.

## Motivazione

L'handoff completo complica stato, responsabilità e audit nelle prime versioni.

## Conseguenze

La decisione deve essere applicata ai task successivi; ogni eccezione richiede un nuovo ADR.
