# Worktree Git per task

- Stato: Accepted
- Data: 2026-08-05

## Decisione

Ogni task usa branch e worktree dedicata.

## Motivazione

Limita interferenze, semplifica diff, rollback e concorrenza.

## Conseguenze

La decisione deve essere applicata ai task successivi; ogni eccezione richiede un nuovo ADR.
