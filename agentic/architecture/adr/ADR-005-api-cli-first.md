# API e CLI prima della UI

- Stato: Accepted
- Data: 2026-08-05

## Decisione

L'MVP espone API REST/SSE e CLI; una UI completa è differita.

## Motivazione

Permette di validare orchestrazione e sicurezza prima di investire nella UX.

## Conseguenze

La decisione deve essere applicata ai task successivi; ogni eccezione richiede un nuovo ADR.
