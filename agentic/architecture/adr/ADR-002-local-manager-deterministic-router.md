# Manager locale e router deterministico

- Stato: Accepted
- Data: 2026-08-05

## Decisione

DeepSeek locale pianifica e suggerisce; il router applicativo decide provider e permessi.

## Motivazione

Privacy, budget e sicurezza non devono dipendere esclusivamente da output probabilistico.

## Conseguenze

La decisione deve essere applicata ai task successivi; ogni eccezione richiede un nuovo ADR.
