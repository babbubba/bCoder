# Modular monolith .NET

- Stato: Accepted
- Data: 2026-08-05

## Decisione

Usare una solution modulare in un unico deployment per ridurre complessità operativa durante l'MVP.

## Motivazione

Microservizi prematuri aumenterebbero failure mode, deployment e osservabilità senza beneficio immediato.

## Conseguenze

La decisione deve essere applicata ai task successivi; ogni eccezione richiede un nuovo ADR.
